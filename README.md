# 김태욱 게임 포트폴리오

게임을 20번 이상 만들어 본 게임 개발자 김태욱입니다. AI와 혼자 만든 게임이 3개, 팀 프로젝트가 10개 이상이고, 나머지는 작은 토이 프로젝트입니다. 떠오른 아이디어는 직접 만들어 보고, 새로운 방식을 시도하는 걸 좋아합니다.

**[포트폴리오 페이지 열기](https://kim-taewook.github.io/Portfolio/)**

## 먼저 볼 세 가지
1. **AI로 만든 게임 3개.** 규칙과 재미는 제가 직접 플레이하며 정하고, 구현은 AI에게 맡겼습니다. 웹에서 바로 해 볼 수 있습니다.
2. **팀 프로젝트 5개.** 팀에서는 기획을 맡아 끝까지 만들었습니다. 다섯 개 모두 행사에 전시했거나 스토어에 올렸고, 피아는 BIC, TGS, G-STAR에서 상을 받았습니다.
3. **기획서 7개.** 레벨 둘, 시스템, 콘텐츠, 밸런스, 보상과 경제, 보드게임이 하나씩입니다. 모두 기획 의도 두 줄로 시작하고, 규칙을 다룬 다섯 개에는 예외 처리 표가, 분석 두 개에는 전제와 한계 표가 있습니다. 팀 프로젝트에서 쓴 기획서까지 합친 25편은 페이지 맨 아래에 분야별로 모았습니다.
